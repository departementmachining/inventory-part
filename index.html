Pengaturan Supabase Database

Masukkan URL dan Anon Public Key Supabase Anda. Jika dikosongkan, aplikasi akan berjalan menggunakan **LocalStorage / Mock Data Mode**. 



                

                    
Petunjuk Script SQL DDL Supabase:

                    
Salin dan jalankan query berikut pada SQL Editor di Dashboard Supabase Anda:

                    
-- 1. Table Categories
CREATE TABLE categories (
  id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
  name TEXT NOT NULL UNIQUE
);

-- 2. Table Products
CREATE TABLE products (
  id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
  sku TEXT UNIQUE NOT NULL,
  name TEXT NOT NULL,
  category TEXT NOT NULL,
  stock INT DEFAULT 0,
  min_stock INT DEFAULT 5,
  unit TEXT DEFAULT 'Pcs',
  created_at TIMESTAMP WITH TIME ZONE DEFAULT timezone('utc'::text, now())
);

-- (Opsional) Jika tabel products lama masih punya kolom harga, boleh dibuang:
-- ALTER TABLE products DROP COLUMN IF EXISTS buy_price, DROP COLUMN IF EXISTS sell_price;

-- 3. Table Stock Transactions
CREATE TABLE stock_transactions (
  id UUID DEFAULT gen_random_uuid() PRIMARY KEY,
  product_id UUID REFERENCES products(id) ON DELETE CASCADE,
  type TEXT CHECK (type IN ('IN', 'OUT')),
  quantity INT NOT NULL,
  notes TEXT,
  created_at TIMESTAMP WITH TIME ZONE DEFAULT timezone('utc'::text, now())
);
